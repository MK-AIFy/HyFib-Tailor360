Sub-issue of #46. Twelfth of thirteen: the **costing-assumptions editor** — the version list, the draft editor for the
overhead percentage, the allocation basis and the per-category, per-service and per-phase labour rates, and publish
with a mandatory reason. It is what makes the labour and overhead inputs **configurable by the Owner** rather than
merely configurable (DOR-11): without it, the only way to change a rate is a direct API call.

Split from `e10-f03-10a` because this is a versioned-master editor, and the nearest equivalent in this repository —
`clients/pwa/src/routes/catalog/CatalogVersionEditorRoute.tsx` — is **994 lines in the file for one route**. A margin
report screen plus an editor of that shape does not fit under the 1,500-line ceiling of CLAUDE.md section 6.

## Acceptance criteria

- [ ] An Owner creates a draft, enters an overhead percentage and one category rate, publishes it with a reason behind
      `ConfirmDialog`, and sees the new version in force — all through the screen, with stubbed transport in the route
      test and over the real API in the evidence.
- [ ] The screen shows all five states: loading (the editor keeps its previous value on reload, per
      `useAdminResource`), empty (no version yet, **with the consequence stated**), error (`FormErrorSummary` for
      validation and `RetryableError` for transport; the raw message is never rendered), offline
      (`NetworkStatusBanner`, with save and publish inside `OfflineBlockedAction`), and forbidden
      (`RequirePermission`'s `EmptyState` with `admin.forbidden.title` / `admin.forbidden.body` — **not** the
      `Forbidden` component, and **no** redirect).
- [ ] **Negative:** editing a **published** version is not offered by the screen at all, and a direct attempt is
      refused by the server and rendered as a refusal the reader can act on.
- [ ] **Negative:** a stale `If-Match` on a draft edit is surfaced as a conflict with a reload and **nothing is
      overwritten**; the entered values are preserved so the Owner does not retype them.
- [ ] **Negative:** a caller without `reports.manage_costing_assumptions` gets `RequirePermission`'s `EmptyState` with
      `admin.forbidden.title` / `admin.forbidden.body` — not the `Forbidden` component, no redirect — and the screen
      issues no request it knows will be refused.
- [ ] **Exception:** publishing a version whose effective window overlaps an already-published one is refused by the
      server and shown in a `FormErrorSummary` **naming the conflicting version**, with the draft's entered values
      preserved; and publishing a draft with neither a rate nor an overhead percentage is refused naming the missing
      field.
- [ ] The forms items of `docs/nfr/a11y-checklist.md` pass, including the error summary being reachable and announced
      and every field having a programmatic label; `expectNoHorizontalOverflow` passes at 320, 360, 768, 1024 and 1280
      px at 100% and 200%; `pnpm --dir clients/pwa lint`, `typecheck`, `test`, `build` and `format:check` are clean,
      and `generate:api:check` reports no drift.

## Migration and rollback

No migration: client-only. Rollback is redeploying the previous client bundle, after which the route disappears and
the assumption versions remain editable through `e10-f03-4`'s routes — which is why a rollback loses no capability,
only convenience. `generate:api:check` proves the generated types match the published interface description.
