Sub-issue of #33, and the second half of the workflow administration client. E06-F02-12 builds `/admin/workflows`, the
`clients/pwa/src/workflows/` module over the eight routes E06-F02-2 and E06-F02-3 publish, and the **read-only** version
view at `/admin/workflows/:definitionId/versions/:versionId`. This slice turns that address into an **editor** for a
`Draft` and adds the publish and retire actions — the half of plan Section 8's sentence that the previous child
deliberately left out: "editor with phase list, transition matrix and graph preview highlighting unreachable phases,
dead ends, missing start/end and phases with no eligible role; publish refused while validation reports errors".

It is its own session on measured evidence from this repository, not on preference.
`clients/pwa/src/routes/catalog/CatalogVersionEditorRoute.tsx` is **994 production lines for one editor route**;
`clients/pwa/src/routes/admin/TemplateVersionEditorRoute.tsx` is 848 before `TemplateFieldForm.tsx` (523) and
`TemplateRuleBuilder.tsx` (330). A phase form, a transition matrix, a graph preview, a findings-to-focus report and two
confirmation flows is that size again, and it could not have shared a pull request with a list route and an eight-route
API module inside the 1,500-line target of CLAUDE.md section 6.

## Scope

- [ ] Turn `WorkflowVersionRoute.tsx` into an editor **when and only when** the version's status is `Draft`: a
      `Published` or `Retired` version keeps the read-only rendering E06-F02-12 built, with its status named and no
      affordance that suggests editing. The server is the authority (every mutator on a non-draft is refused by
      E06-F02-1); the screen states the rule rather than being the rule.
- [ ] The **phase list** panel: code, display name, order, permitted role keys, evidence-required flag, optional and
      skippable flags, expected duration and SLA. Duration and SLA are **empty unless the Owner types one** — no
      suggestion, no placeholder number, no default, and no validation range beyond "a positive duration". No document
      fixes either value, and a placeholder is an invented number a reviewer will treat as a product change.
- [ ] The **transition matrix** panel: a grid of from-phase against to-phase where **every cell is a labelled control
      reachable and operable by keyboard**, and never a drag-only canvas. Each cell's accessible name says both phase
      names and the current state, because a grid of unlabelled checkboxes is unusable with a screen reader. This is
      the control the screen lives or dies by.
- [ ] The **graph preview** panel, built on E06-F02-12's `workflowGraph.ts`: unreachable phases, dead ends that are not
      terminal, a missing or duplicated start, no terminal phase at all, and phases with no permitted role — each named
      **in text** beside any visual cue, never by colour alone (WCAG 1.4.1). The preview is a reading aid: the server's
      validation report is the authority and the screen never decides a version is valid.
- [ ] One `PUT` of the whole draft — phases, transitions and category mapping together, because E06-F02-2 accepts them
      as one payload and a half-edited graph has no meaning — with `If-Match` from the read's `ETag`, and field-level
      errors keyed by phase code mapped back onto the offending row or cell.
- [ ] The validation report through the shared findings component, each finding **moving focus** to the phase row or
      matrix cell its `Target` names, and **publish unavailable with its reason shown beside the action** while any
      `Error` finding stands — beside it, not only in a disabled tooltip, which a keyboard user never sees.
- [ ] Publish and retire through `ConfirmDialog`'s strongest tier with `AdminReasonField`; the step-up demand rendered
      as the step-up prompt with the reason preserved across it (#99); and the consequence stated in the confirmation in
      words: a published version is immutable, a job pinned to it never migrates, and the outgoing published version is
      retired in the same transaction.
- [ ] Extend the `workflows.*` message family in `clients/pwa/src/i18n/messages/workflows.ts` with the editor's words
      in English **and Tamil**, including one sentence per validation finding code so the report reads without the
      server's prose, and one sentence for the retire refusal E06-F02-3 defines.
- [ ] Extend `clients/pwa/src/routes/workflows/WorkflowScreens.test.tsx` and `workflowScreens.stories.tsx` for every
      state in the table below, each story rendering the **real** route through `withAdminApi`.
