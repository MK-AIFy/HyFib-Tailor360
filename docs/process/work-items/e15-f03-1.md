Sub-issue of #61. Plan Section 6.2 note 11 and Section 7 split #61 into #61a, #61b and #61c, and none of the
three has ever been created, so this decomposition creates them as numbered children. This is the first half of
the plan's **#61a**: the risk-based test strategy every later child is measured against, plus the legacy-import
question the parent's fifth implementation step raises. The gap is checkable two ways: `ls docs/qa` fails — the
directory does not exist — and `grep -ril legacy docs/` returns nothing outside `docs/IMPLEMENTATION_PLAN.md`, so
no document in the repository says what a legacy import would have to prove, or whether there is any source data
to import at all.
