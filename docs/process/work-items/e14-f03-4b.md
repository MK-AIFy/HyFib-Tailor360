Sub-issue of #58, and the second half of child 4. Child 4 establishes the Grafana provisioning file, the dashboard lint
test and the panel-to-SLI README, and ships the one dashboard whose every series is already producing — service health.
This issue adds the two dashboards whose series come from #58 child 1's new instruments and from the capacity envelope:
**background and integrity**, and **capacity and release**. It is split from child 4 on size: a Grafana panel with its
targets, `fieldConfig` and thresholds is 60 to 90 lines of JSON, so the three dashboards together are about 1,700 lines
before the provisioning file, the README and the test — over the `CLAUDE.md` section 6 target.

## Acceptance criteria

- [ ] With the `observability` profile up, a web host and a **worker** both exporting, and one outbox message delivered,
      both dashboards load with every panel either rendering data or appearing in the no-producer table — and no panel
      whose query errors.
- [ ] The outbox-lag panel shows **one series per module schema**, and a module whose outbox is empty shows zero rather
      than being absent, which is the contract child 1's gauge declares. Eleven modules, eleven series.
- [ ] Every new panel's description names the `docs/nfr/slo.md` SLI row or the `capacity-and-performance.md` budget row
      it serves and states that the threshold is **proposed**; the README table lists all of them with no row missing on
      either side.
- [ ] **Negative:** no panel query groups by a high-cardinality or personal attribute — not customer, order, invoice,
      payment, media or message identifier, and not a route **parameter value**; route **template**, module, job name
      and instance are what may be grouped on (`docs/nfr/data-classification.md` section 5.18, "In logs" row). The lint
      test child 4 shipped fails such a panel; add a negative control for the new attribute names.
- [ ] **Negative:** the lint test fails when one of these panels names a metric absent from `SignalNames` and the
      allowed instrumentation list — proved by a negative control, not by inspection.
- [ ] **Exception:** stop the worker and the heartbeat-age panel crosses its threshold within twice the heartbeat
      interval while every web-host panel stays green, so "the worker is down" is legible on the dashboard before any
      alert exists. Stop the **exporter** and the panels go to no-data while the no-producer table is unchanged — a
      broken exporter and an unbuilt module must not look alike.
