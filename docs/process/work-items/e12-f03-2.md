Sub-issue of #52. Accessibility is asserted today only where jsdom can decide it, and the code says so:
`clients/pwa/src/design-system/testing/axe.ts` declares `RULES_JSDOM_CANNOT_JUDGE = ['color-contrast',
'target-size']` and disables both "rather than leaving them to report a false pass";
`clients/pwa/.storybook/preview.tsx` lines 121 to 124 set `a11y: { test: 'todo' }` with the comment "Report rather
than block while the system is being built; **#52 owns the enforcing gate**"; and `expectNoHorizontalOverflow.ts`
lines 17 to 31 state that the helper takes a structural `PageLike` precisely so that #52 can "import it and pass a
real page". So three of the four checks `RG-06` demands — rendered contrast, target size, and reflow and obscured
focus measured by a browser — exist as capabilities with no runner. This sub-issue is that runner, over the routes
that exist at HEAD. There is no `.storybook/` directory at the repository root: every Storybook file is under
`clients/pwa/.storybook/`.
