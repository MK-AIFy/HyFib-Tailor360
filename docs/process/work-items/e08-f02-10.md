- [ ] An Inventory Clerk holding `inventory.manage_purchase_orders` creates a three-line draft order at
      `/inventory/purchase-orders/new` in two different purchase units, sees each line's base-unit conversion **in
      words**, places it, and finds it in the list with its `Placed` badge; re-opening it renders read-only.
- [ ] The list pages with "Show more" until `hasMore` is false, filters by status and by supplier, and shows no total
      count, because the API sends none.
- [ ] **One key, one action:** a failed create retried from the screen carries the same `Idempotency-Key`; a success
      replaces it; the same holds for place and for cancel. There is no per-line save anywhere in the screen.
- [ ] **Negative:** a caller without `inventory.manage_purchase_orders` sees the `RequirePermission` empty state
      (`admin.forbidden.title` / `admin.forbidden.body`) on both routes and is **not** redirected; a suspended or
      retired supplier is refused with a sentence and the form keeps the input; an empty line list, a zero quantity
      and a negative unit cost each render against the field they concern rather than as a whole-form error.
- [ ] **Exception:** cancelling a placed order requires a reason, and the cancelled order still renders in full —
      history is appended, never rewritten. Placing an already-placed order renders the server's
      `inventory.purchase-order-not-<state>` refusal as a sentence rather than leaving the button apparently broken.
- [ ] **Offline:** each of the three writes is refused through `OfflineBlockedAction`, posts nothing and queues

      walked on.
- [ ] **Accessibility:** every field has a persistent visible label; the confirmation reads supplier, location, each

      `expectNoHorizontalOverflow` at all its default widths, including the line table at 320 px.
- [ ] **Localisation:** every string is in both `inventoryEn` and `inventoryTa`; the conversion sentence is one

- [ ] `pnpm --dir clients/pwa lint`, `typecheck`, `test`, `format:check` and `build` pass, and `generate:api:check` is
