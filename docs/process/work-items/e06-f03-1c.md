## How an endpoint is declared in this repository

There is one accepted shape and it is not optional. Copy it from
`src/Modules/Billing/Tailor360.Modules.Billing.Api/Invoicing/InvoiceEndpoints.cs` (a write at lines 190-196, a read
at 139-141), which is the closest merged example:

```
    .RequirePermission(<PermissionKey>, BranchScope.CurrentBranch)   // ARCH-007
    .ScopedToResource(<ResourceKinds.Thing>, "<routeValueName>")     // ARCH-023, when the route names a row
    .RequireRateLimiting(RateLimitPolicyNames.Write)                 // ARCH-017, exactly one
    .Audited(<Handler>.<Something>Action, reasonRequired: true)      // ARCH-008, every write
    .RequireIdempotency()                                            // where a client may retry
    .RequireIfMatch()                                                // where the row carries an ETag
    .WithRequestTimeout(RequestTimeoutPolicies.Command)               // every endpoint in the repository has one
```

- Verbs: `Platform.Security/Endpoints/EndpointAuthorisationExtensions.cs` (`RequirePermission(key, scope)`,
  `Audited(action, reasonRequired)`, `AllowAnonymousWithJustification`);
  `ResourceScopeEndpointExtensions.cs` (`ScopedToResource(resourceKind, routeValueName, scope)`, and the
  deliberately noisy exemption verb for a route whose identifier names nothing branch-owned);
  `RequestSafetyEndpointExtensions.cs` (`RequireIdempotency`, `RequireIfMatch`);
  `StepUpEndpointExtensions.cs` (`RequireStepUp`).
- **Rate-limit policies**, all of them, from `Platform.Security/Endpoints/RateLimitPolicyNames.cs`:
  `DefaultUser` = `default-user` (ordinary authenticated read), `Write` = `write` (authenticated state change),
  `ScanBurst` = `scan-burst`, `ExportHeavy` = `export-heavy`, plus `AuthenticationAnonymous`,
  `MultiFactorChallenge`, `RecoveryAnonymous`, `DefaultIp`. There is no other policy, and inventing one is a
  change to the limiter configuration in the web host.
- **Request timeouts**: `Platform.Security/Endpoints/RequestTimeoutPolicies.cs` — `Read` = `read`,
  `Command` = `command`, `Report` = `report`, `Export` = `export`. **Every** endpoint in `src/Modules/` carries one
  today (grep `WithRequestTimeout` — there is no exception), so an endpoint without one is the odd one out.
- **Branch scopes** from `Platform.Abstractions/Multitenancy/BranchScope.cs`: `CurrentBranch` (the default),
  `AssignedBranches`, `Organisation`, and the member that demands no branch reach at all.
- **Resource kinds**: each module keeps its own constants class — `BillingResourceKinds`,
  `MeasurementResourceKinds`, `DesignSelectionResourceKinds` — in its `Application` project, with an
  `IResourceScopeResolver` per kind in its `Infrastructure` project, registered with `TryAddScoped`.
