## Acceptance criteria

- [ ] An Owner creates a price list with a code and a name at `/admin/price-lists`, opens it, starts a draft version
      with a first day, an explicit inclusive-or-exclusive choice, a round-off rule, an override threshold and at
      least one branch, and sees the draft listed with those conventions — no deployment, no database access.
- [ ] Cloning an existing version of the same list starts a draft that reports the version it was cloned from.
- [ ] **Negative, duplicate code:** a second list taking an existing code is refused with
      `billing.code-not-unique` rendered as a sentence against the code field, the typed values stay, and a retry
      reuses the same `Idempotency-Key`.
- [ ] **Negative, an omitted money-bearing choice:** submitting the draft form without the inclusive-or-exclusive
      choice, without a round-off rule, without a threshold, without a first day or with no branch is refused, and
      the message names the field. The client does not fill any of them in on the person's behalf, and the test
      asserts the request body carried no value the person did not type.
- [ ] **Negative, concurrency:** a rename sent with a stale `If-Match` answers `billing.price-list-changed` — not
      `billing.version-changed` — and the screen offers a re-read and a retry, never a silent overwrite.
- [ ] **Negative, authorisation:** a caller without `billing.manage_price_lists` meets `RequirePermission`'s
      `EmptyState`, never a redirect, and the destination is absent from the administration navigation. The test
      also asserts the screen handles the **server's** refusal of a write, because the claim list can be stale.
- [ ] **Negative, another organisation's branch:** a draft naming a branch the organisation does not own is refused
      with `billing.branch-not-known`, which the server settles
      (`RefusesAnotherOrganisationsBranchToAVersionAndToARegistration`); the picker never offers one, and the screen
      renders the refusal rather than assuming the picker is the only route in.
- [ ] **Exception path:** a published or retired version offers no convention-changing control; the screen says a
      change is a clone of it into a new draft, and the clone control is the way out. A list is never deleted, and
      the screen offers no deletion.
- [ ] **Offline:** create, rename and start-a-draft render `OfflineBlockedAction` — "Needs connection — this will
      not be queued", word for word.
- [ ] The override threshold is shown as a percentage through `formatPercent` and read through `parseNumber`, never
      as a fraction and never with `toLocaleString` at a call site.
