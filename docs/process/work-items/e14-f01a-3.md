## What is already built (do not re-build)

**The customer and measurement flow is live code, not a design.** Model what is there.

- `src/Modules/Customers/` — all five projects populated; schema `customers`, declared at
  `Tailor360.Modules.Customers.Infrastructure/Persistence/CustomersDbContext.cs:45`. Seven migrations create
  nineteen tables: `customers`, `customer_aliases`, `customer_branch_visibility`, `consent_purposes`,
  `consent_wordings`, `consent_records`, `communication_preferences`, `duplicate_candidates`, `customer_merges`,
  `customer_exports`, `measurement_templates`, `measurement_template_versions`, `measurement_template_fields`,
  `measurement_drafts`, `measurement_draft_values`, `measurement_versions`, `measurement_version_values`,
  `outbox_messages`, `inbox_messages`. **Note the real name `measurement_version_values`** — the name
  `measurement_values` in `docs/architecture/module-ownership.md` section 5 is the plan's, not the schema's.
- Thirty-four endpoint registrations across `Tailor360.Modules.Customers.Api/`, forty published operations under the
  `Customers` tag of `docs/api/openapi.v1.json`. The ones this model must enumerate by route include
  `POST /api/v1/customers/{customerId}/export` and `GET /api/v1/customers/{customerId}/exports/{exportId}`
  (`Customers.Api/Customers/CustomerEndpoints.cs:124` and `:177`), `POST /{customerId}/merge` (`:590`),
  `GET /{customerId}/duplicates` (`:548`), `POST /{customerId}/open` (`:502`), and the measurement capture and
  template surfaces in `Api/Measurements/`.
- `Customers.Application/Customers/CustomerExportHandler.cs` and `CustomerExportDocument.cs` — the personal-data
  export, already built and already audited. It is the concrete instance of export leakage in this flow.
- `Customers.Domain/Naming/CustomerNameNormaliser.cs`, `LatinFolding.cs`, `TelephoneNumber.cs`,
  `Deduplication/DuplicateScoring.cs` — the matching and scoring rules an enumeration attack would abuse.
- `Customers.Contracts/` (11 files) — `ICustomerSnapshotQuery`, `IMeasurementSnapshotQuery`,
  `IMeasurementTemplateQuery`, `IConsentQuery`, `ICommunicationPreferenceQuery`, and the events `CustomerMerged`,
  `MeasurementVersionConfirmed`, `MeasurementTemplateVersionEvents`, `CustomerConsentEvents`, `PreferencesChanged`.
  Cross-module reach is through these and nothing else (ARCH-004).
- `src/Modules/Customers/Tailor360.Modules.Customers.Infrastructure/Persistence/CustomerTimelineSource.cs` — the
  only implementation of `Tailor360.Platform.Abstractions.Ports.ITimelineSource`; the customer timeline is composed
  in the host at `src/Hosts/Tailor360.Web/Endpoints/CustomerTimelineEndpoints.cs`, so it is a host-level read over
  several modules and the model must say so.
- `docs/security/field-visibility.md` (#24) — response view × field × class × permission. Two of its five views are
  served today, `customers.record` and `customers.search_card`. This is the existing control against
  over-disclosure; cite it, do not re-derive it.

**The customer-link flow is not built either.**

- `src/Modules/Notifications/` holds seven scaffolding files; no table, no endpoint. Plan Section 6.2 note 9 fixes
  the design: #32a creates `notifications.customer_links` (token hash, purpose, subject reference, branch, expiry,
  revocation, rate-limit counters) plus `ICustomerLinkIssuer` / `ICustomerLinkResolver` and the justified anonymous
  route `/c/estimate/{token}`; #48 adds the `status` purpose, #49 `feedback`. `docs/architecture/module-ownership.md`
  line 635 gives the table's columns as `SHA-256(token)`, purpose, subject ids, expiry, revocation, use count,
  rate-limit counters. Open sub-issue #211 is the one that builds it; #213 carries the feedback token.
- `docs/nfr/traceability.md` `NFR-SE-14` states the required properties: random, purpose-bound, expiring, revocable,
  rate-limited, stored only as a hash, with `/c/**` redacted from logs and traces.
- `docs/security/threat-models/authentication.md` already declares this flow out of its own scope and points here
  ("The customer's expiring purpose-bound links … Covered by `threat-models/customer-links.md` (#56a)"), so the
  hand-off is already written down and must be honoured in that direction.
