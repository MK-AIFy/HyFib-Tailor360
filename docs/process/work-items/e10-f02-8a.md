browser**, which is why it is separated from the quality dashboard and why its evidence is different. The designed
prototype exists: `clients/pwa/src/stories/journeys/TailorMasterWorkboard.tsx`, **478 lines**, with its accessibility

routes; the quality dashboard is E10-F02-8b, split because three screens at this repository's measured rates — one

## Acceptance criteria

- [ ] A Tailor Master holding `reports.read` and `reports.read_workload` opens `/reports/workload`, reads one row per
      assignee with open phases, oldest queue age and the period's completions, sees the unassigned row, and reads the
      context panel (**A11Y-RJ-04** steps 1 and 2 in their read-only form).
- [ ] **Negative — the withheld columns:** an Auditor holding `reports.read` alone sees the open-work columns and a
      named, actionable explanation of the missing throughput figures — **not zeros and not an error**. A test asserts
      the words are present and that **no numeric throughput cell exists in the table at all**.
- [ ] **Negative — forbidden:** a Tailor reaching either route sees the `RequirePermission` empty state with
      `admin.forbidden.title` / `admin.forbidden.body` and is **not** redirected.
- [ ] **Negative — the read fails:** a `500` renders `AuthProblemAlert` in plain language with a retry that reuses the
      same request; never a code, never a stack trace.
- [ ] **Negative — offline:** the shell banner says so, nothing is queued, and no figure is presented as current.
- [ ] **Negative — no leaderboard:** a test asserts the default order is by open work, that **no control offers "rank
      by completions"** or any throughput sort, and that the context panel is rendered unconditionally rather than
      behind a disclosure.
- [ ] **Negative — no name in a URL:** a test asserts the assignee filter in the query string carries an identifier and
      never a display name.
- [ ] **Exception — a member of staff who has left:** their row still appears for a past period, marked inactive from
      the server's flag, and their display name is whatever the directory answers — the screen invents no name and does
      not fall back to showing an identifier as if it were one.
- [ ] **Exception — an empty branch:** the unassigned row with zeroed counts and an `EmptyState` naming the filter,
      with the as-of instant.
- [ ] The status strip shows the data-as-of and reconciliation state on the workload screen (**A11Y-RJ-08** step 7's
      rule, applied here).
- [ ] No axe violation and no horizontal page scroll at any of the five default widths at 100% and 200% zoom, on both
      screens.
