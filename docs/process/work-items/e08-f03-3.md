## Acceptance criteria

- [ ] An Inventory Clerk holding the new key acknowledges an open alert over HTTP and the alert leaves the open
      queue; a second acknowledge of the same alert is refused `409` with a stable code rather than silently
      succeeding.
- [ ] A snooze until a stated instant removes the alert from the queue until that instant, and the next evaluation
      pass after it re-presents the alert **without** creating a second row — the de-duplication key from
      `E08-F03-2` still holds.
- [ ] An alert left unacknowledged beyond the branch policy's escalation delay is escalated **exactly once** and
      publishes `inventory.low-stock-escalated.v1` exactly once, carrying the policy's `targetRoles` and the instant
      the alert was raised — asserted by running the pass twice past the delay and counting both the transitions and
      the outbox rows. Who is actually told is `E08-F03-3b`'s acceptance criterion, not this child's.
- [ ] **Negative:** a caller without `inventory.acknowledge_alert` gets `matrix.yaml`'s `not-permitted` answer —
      `403` with `security.forbidden`; a caller at another branch acknowledging this branch's alert by pasting its
      identifier gets the `out-of-reach` answer — `404` with **`security.resource-not-found`**, not a bare 404
      (`tests/Tailor360.IntegrationTests/Authorization/matrix.yaml` lines 29–47 define every answer in one place;
      `IdentifierEditingTests.cs` is what reads the dimension).
- [ ] **Negative:** a snooze with no reason is refused by the audit filter's `reasonRequired` before it reaches the
      domain, and a snooze to a past instant is refused with a field-level problem detail.
- [ ] **Exception:** when the branch policy names no target role, the alert still raises, still escalates and still
      appears in the queue, and the event carries an **empty** `targetRoles` array rather than being withheld — so
      that `E08-F03-3b` can write the suppression row #209's "nothing is silently dropped" rule requires. Withholding
      the event instead would make the suppression unrecordable, which is the failure mode that rule exists to
      prevent.
- [ ] No metric attribute carries an item name, a supplier name or a cost — asserted by a test over the emitted
      attribute keys, not by inspection.
