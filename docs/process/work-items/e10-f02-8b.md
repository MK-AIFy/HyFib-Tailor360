Sub-issue of #45. The parent asks for a "quality dashboard with context (no misleading staff ranking)". This slice is
that screen, over E10-F02-4b's two reads, and its whole design follows from one fact: **neither payload has a field a
person could be named in**, so the screen cannot rank anybody even by accident. It is split from the workload screens
because three read-only screens in one session exceeds this repository's measured rates — one route in
`clients/pwa/src/routes/catalog/CatalogVersionEditorRoute.tsx` is 978 production lines — and because its evidence is
simpler: no Personal data, no withheld columns, no DC-06 release gate.

## Acceptance criteria

- [ ] A Branch Manager holding `reports.read` opens `/reports/quality` from the hub and reads every rate **with its
      numerator and denominator**, the excluded counts, the reason-code Pareto and the period trend, with the data-as-of
      and reconciliation state from the status strip visible (**A11Y-RJ-08** steps 1, 2, 3 and 7).
- [ ] The chart's data **is** in the table, the table is always rendered, its scroll region is focusable, and the SVG is
      `aria-hidden` with its rectangles sized by attributes — asserted by a test.
- [ ] The reason shares sum to 100% of the period's failures within the stated rounding, and the screen shows the
      rounding rule rather than leaving a one-percent gap unexplained.
- [ ] **Negative — forbidden:** a Tailor reaching `/reports/quality` sees the `RequirePermission` empty state with
      `admin.forbidden.title` / `admin.forbidden.body` and is **not** redirected.
- [ ] **Negative — the read fails:** a `500` renders `AuthProblemAlert` in plain language with a retry that reuses the
      same request; never a code, never a stack trace.
- [ ] **Negative — offline:** the shell banner says so, nothing is queued, and no figure is presented as current.
- [ ] **Negative — no person is nameable:** a test asserts the rendered output contains no staff name and no staff
      identifier, and that the screen has no control that would group or order by a person. This is a test because it is
      the parent's "avoid misleading staff ranking" criterion, and a prose promise cannot fail a build.
- [ ] **Negative — a narrowed answer:** when the server reports it covered fewer branches than were asked for, the
      screen says which branches the figures cover.
- [ ] **Exception — a zero denominator:** a period in which nothing reached QC reads **"no data"** for every rate, with
      the excluded count explaining why, and never `0%`. A test asserts the words and the absence of a numeral.
- [ ] **Exception — an empty shop:** an `EmptyState` naming the filter, with the as-of instant, never a 404-looking
      screen.
- [ ] **Exception — the dashboard holds still:** nothing re-orders or refreshes under the reader's hands; a test asserts
      no interval is started (**A11Y-RJ-08** step 8, WCAG 2.2.2).
- [ ] No axe violation and no horizontal page scroll at any of the five default widths at 100% and 200% zoom.

container rather than the page, and result counts and state changes are announced politely.
